Hiểu công nghệ của game Não bỏng ngô

Tài liệu cho cả nhóm, không cần biết lập trình

1Web app hoạt động thế nào?

Game của tụi mình là một web app: một trang web chạy ngay trên trình duyệt của điện thoại, không cần tải từ cửa hàng ứng dụng. Mọi trang web đều gồm 3 phần.

HTML

Bộ xương
Chữ, nút bấm, hình ảnh nằm ở đâu.

CSS

Quần áo
Màu sắc, kích cỡ, cách sắp xếp.

JavaScript

Bộ não
Chuyện gì xảy ra khi bạn chạm, tính giờ, tính điểm.

Các công cụ ở phần sau chỉ giúp viết ba thứ này nhanh và ít lỗi hơn.

2Từng công cụ trong một thẻ

Mỗi thẻ gồm: công cụ là gì, ví dụ đời thường, và vì sao tụi mình chọn nó.

Node.js và npm

Hộp đồ nghề

Là gì: Node.js giúp máy tính chạy JavaScript ngoài trình duyệt. npm là "cửa hàng" tải các bộ phận code làm sẵn.

Ví dụ đời thường: Node là xưởng thủ công, npm là tiệm bán linh kiện.

Vì sao dùng: React, Vite và hầu hết công cụ khác đều cài qua npm.

npm install   # tải linh kiện
npm run dev   # chạy thử game

React

Dựng màn hình

Là gì: Thư viện giúp ghép giao diện từ những mảnh nhỏ, dùng lại được, gọi là component.

Ví dụ đời thường: LEGO. Làm một viên nút bấm một lần, rồi dùng ở mọi màn hình.

Vì sao dùng: Khi điểm hay màn hình thay đổi, React tự vẽ lại. Không phải làm tay.

Vite

Bếp chạy nhanh

Là gì: Công cụ chạy thử game ngay trên máy và đóng gói game thành các file nhỏ gọn để đưa lên mạng.

Ví dụ đời thường: Lúc nấu, bạn nếm thử tức thì. Nấu xong, Vite xếp món vào hộp mang đi.

Vì sao dùng: Đơn giản và nhanh nhất để bắt đầu một app React.

CSS

Màu sắc và hình dáng

Là gì: CSS là phần "quần áo". Tụi mình dùng các biến màu như --primary cho màu cam.

Ví dụ đời thường: Bảng màu của họa sĩ. Đổi một ô màu, cả bức tranh đổi theo.

Vì sao dùng: Không cần học thêm framework. Đổi một màu ở một chỗ, cả app cập nhật.

SVG

Hình vẽ bằng toán

Là gì: Hình ảnh được mô tả bằng hình tròn, đường cong trong code, không phải các điểm ảnh.

Ví dụ đời thường: Bản vẽ kỹ thuật: phóng to bao nhiêu vẫn nét.

Vì sao dùng: Hạt Bắp luôn sắc nét, file nhẹ, và đổi được tâm trạng (bình tĩnh, nổ tung...) bằng code.

content.js và scoring.js

Chữ và phép tính

Là gì: content.js chứa toàn bộ chữ tiếng Việt. scoring.js chứa công thức tính điểm.

Ví dụ đời thường: content.js là quyển kịch bản của vở kịch. scoring.js là máy tính bấm điểm.

Vì sao dùng: Nhóm sửa câu chữ trong content.js mà không đụng vào code. Công thức tách riêng nên ít lỗi.

localStorage

Sổ tay trong điện thoại

Là gì: Một ô nhớ nhỏ trong trình duyệt. Đóng tab rồi mở lại, dữ liệu vẫn còn.

Ví dụ đời thường: Cuốn sổ nằm trong cặp của chính người chơi. Chỉ điện thoại đó đọc được.

Vì sao dùng: Lưu điểm Ngày 1 và tiến độ thử thách mà không cần đăng nhập. Mất khi xóa dữ liệu trình duyệt hoặc đổi máy.

localStorage.setItem("day1Score", "74")

Google Sheet và Apps Script

Hòm thư nghiên cứu

Là gì: Apps Script là đoạn code chạy trong Google. Game gửi kết quả đến đó, nó ghi thêm một dòng vào Sheet.

Ví dụ đời thường: Hòm thư. Game bỏ thư (kết quả ẩn danh), Google xếp vào bảng tính.

Vì sao dùng: Miễn phí, cả nhóm quen Sheet nên vẽ biểu đồ cho báo cáo rất dễ. Chỉ gửi khi người chơi tích đồng ý, không có tên.

API key và proxy

Quan trọng nhất

Là gì: API là cánh cửa để chương trình này nhờ chương trình khác. API key là mật khẩu của cánh cửa đó. Ai có key sẽ tiêu tiền của chúng ta.

Ví dụ đời thường: Học sinh không biết mã két của trường. Muốn lấy đồ thì nhờ văn phòng, văn phòng mở két.

Vì sao dùng: Mọi thứ trong code của app, người chơi đều xem được. Vì vậy key không được để trong app. App chỉ nói chuyện với "văn phòng" của mình (proxy trên Vercel). Chỉ văn phòng giữ key và gọi DeepSeek.

Quy tắc vàng: không gửi key trong chat, không dán vào code, không chụp màn hình. Chỉ để trong cài đặt Vercel. Lộ key là người lạ tiêu hết tiền của nhóm.

Vercel

Chỗ đặt game trên mạng

Là gì: Dịch vụ lưu trữ miễn phí. Nối với GitHub thì mỗi lần cập nhật code, link game tự đổi mới. Có thêm "văn phòng" (serverless function) chạy khi được gọi.

Ví dụ đời thường: Một cửa hàng online tự bày hàng mới khi bạn gửi hàng lên.

Vì sao dùng: Miễn phí, chứa cả game lẫn proxy AI, và cho một link duy nhất để làm mã QR.

Trợ lý AI DeepSeek và lớp an toàn

Bộ não của Hạt Bắp

Là gì: DeepSeek là mô hình AI giống ChatGPT, tụi mình gọi qua API. App gửi kèm luật riêng ("chỉ nói về tập trung, không chẩn đoán bệnh") và kết quả của người chơi.

Ví dụ đời thường: Hạt Bắp như người cố vấn đã được dặn kỹ trước khi gặp bạn.

Vì sao dùng: Là học sinh dùng nên cần thêm 3 lớp an toàn: (1) có từ khóa khủng hoảng thì không gọi AI mà hiện lời nhắn tìm người lớn và số hỗ trợ; (2) giới hạn chủ đề; (3) tối đa 20 tin nhắn mỗi ngày, trả lời ngắn.

PWA

Web như app thật

Là gì: Trang web kèm tên, biểu tượng và khả năng lưu sẵn file để chạy khi mất mạng.

Ví dụ đời thường: Một tờ báo bạn cắt dán lên bàn học, mở lúc nào cũng được.

Vì sao dùng: Có thể "Thêm vào màn hình chính", mở toàn màn hình, chạy offline (trừ phần AI). Sau này bọc thành file APK bằng Capacitor nếu cần.

Git và GitHub

Điểm lưu và kho chung

Là gì: Git ghi lại các "điểm lưu" của code, luôn quay lại được. GitHub là kho trực tuyến để cả nhóm xem.

Ví dụ đời thường: Như nút Save trong game, kèm bản sao lưu trên mây.

Vì sao dùng: Vercel lấy code từ GitHub để đưa lên mạng. Mọi người thấy ai sửa gì.

Vitest

Kiểm tra phép tính

Là gì: Công cụ chạy các bài kiểm tra tự động nhỏ.

Ví dụ đời thường: Giáo viên chấm đáp án: nhập thử, so với kết quả đúng.

Vì sao dùng: Điểm số là cốt lõi của Màn 1. Test đảm bảo chạm 2 lần ở game đặt điện thoại thì luôn ra nguy cơ 50.

Xây dựng trong 6 bước, bước nào cũng chơi được

Làm xong bước nào là chạy thử được bước đó, giống đường thử thách 7 ngày trong game.

1
Dựng khungVite + giao diện + Bắt đầu, Game 1, kết quả đơn giản. Đưa lên Vercel.
2
Game 2 đến 4Thêm 3 game còn lại, câu hỏi tự đánh giá, tính điểm có test, 2 màn kết quả.
3
Màn 2 và Kế hoạch8 tình huống tìm lý do lướt, ra kế hoạch 3 giải pháp.
4
Trợ lý AIProxy, khung chat, câu trả lời dự phòng khi mất mạng.
5
Thử thách 7 ngàyĐường 7 ngày, chơi lại Màn 1 ở Ngày 7 để so sánh.
6
Hoàn thiệnGửi dữ liệu lên Sheet, chế độ demo, PWA, chỉnh cho đẹp.

Thử nghiệm với bạn bè

Mời 10 đến 20 bạn cùng lớp chơi thử. Nhìn xem họ có bị kẹt chỗ nào không, rồi chỉnh các ngưỡng điểm (Thấp dưới 40, Trung bình 40 đến 69, Cao từ 70) cho hợp lý.

Nhóm cần chuẩn bị

  • API key DeepSeek, để trong cài đặt Vercel (không để trong code, không gửi qua chat).
  • Tài khoản Google cho Sheet, cùng tài khoản Vercel và GitHub (đều miễn phí).
  • Xem lại chữ tiếng Việt trong content.js: đoạn đọc, câu hỏi, tình huống.
  • 10 đến 20 bạn cùng lớp để chơi thử và chỉnh ngưỡng điểm.
